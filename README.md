# MT-Mate

학생회와 동아리 MT를 준비하는 기획자를 위한 엑셀형 웹 대시보드입니다.

## 제작 목적

MT를 준비할 때 참가자 명단, 입금 여부, 숙소 후보, 교통비, 예산, 일정표, 게임 후보를 따로따로 정리하면 누락이 생기기 쉽습니다. MT-Mate는 여러 자료를 한 화면에서 표 형태로 정리하고, 수정·복사·CSV 다운로드·백업까지 할 수 있도록 만든 웹앱입니다.

## 주요 기능

- 참가자 명단 관리
  - 이름, 연락처, 참석 여부, 입금 여부, 입금액, 메모를 표에서 바로 수정
  - 계열 MT일 때만 학번 칸 표시 가능
  - 여러 명 명단 붙여넣기 추가
  - CSV 다운로드 및 표 복사

- 숙소 후보 비교
  - 지역 선택형 입력
  - 최근 선택 지역 최대 3개 표시
  - 숙소명, 링크, 최대 인원, 기준 인원, 기준가, 추가금, 예상 인원, 박수 입력
  - 총 숙소비와 1인당 숙소비 자동 계산
  - 방 개수, 화장실, 시설 등은 필요할 때만 추가정보로 입력

- 교통비 정리
  - 개별 이동, 택시비 지원, 버스 대절 등 교통 방식 관리
  - 총 교통비, 지원금, 실부담액, 1인당 비용 자동 계산

- 계산 정리
  - 선택 숙소비, 교통비, 음식비, 기타 비용을 합산
  - 총 예상 금액과 1인당 예상 금액 계산
  - 음식/식비 계획표 작성

- 일정표 작성
  - 날짜/일차, 시작 시간, 종료 시간, 일정, 장소, 담당자, 준비물, 메모 정리
  - CSV 다운로드 및 인쇄 가능

- 게임 후보 정리
  - 게임명, 인원, 시간, 준비물, 룰, 더 재밌게 하는 방법, 주의점 정리
  - 후보/선택/보류 상태 관리

- 공유와 백업
  - 각 표 CSV 다운로드
  - 표 복사 후 엑셀에 붙여넣기 가능
  - 전체 JSON 백업 다운로드
  - JSON 백업 가져오기
  - 삭제한 항목 휴지통 복구

## 실행 방법

1. 이 저장소를 다운로드합니다.
2. `index.html` 파일을 브라우저에서 엽니다.
3. 데이터를 입력하면 자동으로 브라우저 localStorage에 저장됩니다.

## GitHub Pages 배포 방법

1. GitHub 저장소를 생성합니다.
2. `index.html`, `style.css`, `script.js`, `README.md`를 업로드합니다.
3. Settings → Pages로 이동합니다.
4. Branch를 `main`으로 선택하고 저장합니다.
5. 생성된 GitHub Pages 링크로 접속합니다.

## 주의 사항

이 프로젝트는 서버가 없는 정적 웹사이트입니다. 따라서 여러 사용자가 동시에 같은 데이터를 실시간으로 편집하는 기능은 지원하지 않습니다. 대신 JSON 백업/가져오기 기능을 통해 한 사람이 정리한 데이터를 다른 사람에게 전달하고 이어서 사용할 수 있습니다.

개인정보가 포함될 수 있는 참가자 연락처, 학번 등은 공개 저장소나 공개 링크에 실제 정보로 입력하지 않는 것이 좋습니다.
