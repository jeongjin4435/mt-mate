# MT-Mate

학생회와 동아리 MT를 준비할 때 필요한 내용을 한 번에 정리할 수 있는 웹앱입니다. 숙소 후보, 참가자 명단, 입금 여부, 교통비, 일정표, 예산 계산, 게임 후보, 준비물, 역할 분담을 HTML, CSS, JavaScript만으로 구현했습니다.

## 제작 목적

MT를 기획할 때 숙소 비교, 참가자 명단, 회비 입금 여부, 교통비, 시간표, 게임 후보, 준비물 등이 여러 곳에 흩어져 있으면 관리가 어렵습니다. MT-Mate는 기획자가 반복해서 정리해야 하는 내용을 웹에서 한 번에 관리할 수 있도록 만든 프로젝트입니다.

## 사용 기술

- HTML
- CSS
- JavaScript
- localStorage
- GitHub Pages

## 주요 기능

### Participants
- 참가자 이름, 학번, 전화번호 입력
- 참석 여부 정리
- 입금 여부 체크
- 검색 및 입금 상태 필터
- CSV 내보내기

### Lodging
- 숙소명, 지역, 링크, 기준 가격, 기준 인원 입력
- 추가 인원 요금 계산
- 총 숙소비 및 1인당 숙소비 계산
- 방 개수, 화장실 개수, 시설, 장단점 기록
- 지역별 필터와 정렬 기능

### Transport
- 버스 대절, 택시비 지원, 개별 이동 등 교통 방식 정리
- 총 교통비, 지원금, 실부담금 계산
- 1인당 교통비 계산

### Schedule
- 날짜, 시작 시간, 종료 시간, 일정 제목 입력
- 장소, 담당자, 준비물, 메모 정리
- 시간순 정렬
- 일정표 인쇄 기능

### Budget
- 숙소비, 인원 추가금, 교통비, 식비, 게임 준비비, 예비비 계산
- 음식 계획 항목 추가
- 총 예상 비용 및 1인당 예상 비용 계산

### Games
- MT 게임 후보 카드 제공
- 게임별 규칙, 진행 방법, 더 재밌게 하는 팁, 주의사항 확인
- 카테고리 필터
- 선택한 게임 저장

### Checklist
- 준비물 추가 및 완료 체크
- 카테고리별 준비물 관리
- 완료율 진행률 표시

### Roles
- 역할 분담표 작성
- 담당자, 업무, 마감일, 상태 관리

## JavaScript 활용 내용

- DOM 조작
- 이벤트 리스너
- 배열 filter, sort, map 활용
- 계산 기능
- 모달창
- localStorage 저장
- 폼 입력값 처리
- 다크모드 저장
- CSV 파일 생성
- 인쇄 기능

## 실행 방법

1. 파일을 다운로드합니다.
2. `index.html`을 브라우저에서 실행합니다.
3. 각 메뉴를 클릭해 기능을 사용할 수 있습니다.

## GitHub Pages 배포 방법

1. GitHub에서 `mt-mate` 저장소를 생성합니다.
2. `index.html`, `style.css`, `script.js`와 나머지 HTML 파일을 업로드합니다.
3. Settings → Pages로 이동합니다.
4. Branch를 `main`으로 설정합니다.
5. 배포된 링크를 확인합니다.

## 주의사항

이 프로젝트는 서버와 데이터베이스 없이 브라우저의 localStorage에 데이터를 저장합니다. 실제 학번, 전화번호 등 개인정보를 입력할 경우 개인 기기에서만 사용하고, 공용 PC나 공개 환경에서는 주의해야 합니다.
